# BNSCL 1.0.0

## Русский

Первый публичный релиз автономной утилиты очистки рабочего набора Blade & Soul NEO.

- компактный интерфейс в тёмном стиле;
- назначаемая глобальная горячая клавиша;
- отображение памяти до и после очистки;
- автоматическая установка `winmm.dll` и `plugins\bnscleaner.dll`;
- резервное копирование заменяемых файлов;
- без лицензирования, телеметрии и сетевых запросов;
- single-file `BNSCL.exe` без встроенного .NET Runtime.

Требуется Windows x64 и .NET 8 Desktop Runtime. Перед установкой плагина игру необходимо закрыть.

## English

First public release of the standalone Blade & Soul NEO working-set cleaner.

- compact dark user interface;
- configurable global hotkey;
- before/after memory reporting;
- automatic installation of `winmm.dll` and `plugins\bnscleaner.dll`;
- backups for replaced files;
- no licensing, telemetry, or network requests;
- single-file `BNSCL.exe` without a bundled .NET runtime.

Requires 64-bit Windows and the .NET 8 Desktop Runtime. Close the game before installing the plugin.
