# BNSCL 1.1.0

## Русский

- Старый загрузчик заменён на безопасный LoaderU.
- `bnscleaner.dll` теперь устанавливается в `BNSR\Binaries\Win64\LoaderU`.
- При обновлении удаляется только старая копия `plugins\bnscleaner.dll`; чужие плагины не затрагиваются.
- Горячая клавиша по умолчанию изменена с `Alt+F2` на `Alt+C`.
- Интерфейс и нативный плагин по-прежнему не используют аккаунты, лицензии, телеметрию или сеть.

Полностью закройте Blade & Soul NEO, запустите BNSCL 1.1.0 и нажмите «Установить плагин».
Контрольные суммы файлов опубликованы в `SHA256.txt`.

## English

- Replaced the legacy loader with the safe LoaderU proxy.
- `bnscleaner.dll` is now installed into `BNSR\Binaries\Win64\LoaderU`.
- Upgrading removes only the legacy `plugins\bnscleaner.dll`; unrelated plugins are preserved.
- Changed the default hotkey from `Alt+F2` to `Alt+C`.
- The controller and native plugin still use no accounts, license checks, telemetry, or network access.

Close Blade & Soul NEO completely, run BNSCL 1.1.0, and click **Install plugin**.
File checksums are published in `SHA256.txt`.
